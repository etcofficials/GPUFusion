# data/

Runtime data written by development builds of GPU Fusion (via `build/<preset>/bin/GPUFusion.datadir`):

- `config/settings.json` — user settings (versioned JSON)
- `logs/` — rotating application logs
- `benchmarks/` — benchmark results (JSON/CSV), from Phase 7
- `reports/` — exported diagnostic reports, from Phase 6
- `audit/` — Phase 0 environment audit and probe output

Everything here except this README is machine-specific and excluded from version control.
